# 005: EUR as the base currency across the stack

## Why
We launch in Ireland, so prices, budgets and invoices are in euro (D-010). Today GBP is hard-coded across the stack. The change touches files in every lane, so this task runs alone, after tasks 002-004 are merged, while the other lanes pause. The rename of `brain` to `compiler` was taken out of this task by D-013 and is parked until after go-live.

## Context
- Decisions: D-008 (Ireland first), D-010 (EUR), D-013 (priority order; rename parked)
- About 50 hard-coded `GBP`/`£` references outside `docs/`: models and seed data in campaign-api, `ruleset.py`, the simulator, bidder tests, `apps/web/lib/utils.ts`, the analytics agent (`spend_gbp`)

## Files you may touch
This is the one cross-lane task. Any file is allowed, except `contracts/`, `handbook/`, `docs/DECISIONS.md` and `tasks/`. List any of those that need changes in the Builder report, and the planner will update them.

## Scope
1. Add a `currency` field (ISO code, default `EUR`) to advertisers and campaigns, and to the compiled snapshot (`packages/ruleset`). Existing demo rows keep `GBP`, and new ones default to `EUR`.
2. Bidder: the bid response `cur` is the campaign's currency. Only bid when that currency is in the request's `cur` list, or the list is empty.
3. Simulator: Irish screens send `cur: ["EUR"]`, UK screens `["GBP"]`.
4. UI and agents: format money with the currency code (`Intl.NumberFormat`). Rename `spend_gbp` to `spend` with a currency field.
5. Update the seed data so the demo advertiser and its Dublin campaigns are EUR.

## Out of scope
- Converting between currencies (not needed while each campaign has one currency)
- Renaming `services/brain` (parked by D-013)
- Changes to `docs/` history files

## Acceptance criteria
- [ ] `grep -rnE "GBP|£" --exclude-dir=docs --exclude-dir=.git .` finds matches only in tests, fixtures, UK simulator screens and legacy-row handling. List what remains in the Builder report
- [ ] `docker compose -f infra/docker-compose.yml up -d --build` starts cleanly and the console shows EUR amounts for the demo advertiser
- [ ] An Irish campaign bids with `cur: EUR`. A campaign in EUR does not bid on a request whose `cur` is only GBP. Add a matcher test for each
- [ ] CI is green
